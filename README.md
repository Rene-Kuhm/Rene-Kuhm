## Flagship project

### [flow-engineering](https://github.com/Rene-Kuhm/flow-engineering)

**Active · Python 3.12+ · CLI · optional MCP server · MIT**

An opinionated orchestration framework for spec-driven, AI-assisted software delivery. It connects intent, project context, persistent decisions, implementation, verification, and archival in one explicit workflow.

The repository includes a Python package, command-line interface, optional read-only MCP adapter, automated tests and CI, security and contribution policies, architecture documentation, and versioned change governance.

`INTENT → CONTEXT → SPEC → TASKS → APPLY → VERIFY → ARCHIVE`
